# Lista de Exercícios Nivelados — Arrays em PHP Básico (Aula 02)

Série de **20 exercícios progressivos** sobre **Arrays em PHP**, elaborada apenas com recursos introdutórios:
- **Permitido:** variáveis, operadores aritméticos (`+`, `-`, `*`, `/`, `%`), concatenação (`.`), `echo`, `print_r()`, `count()`, `unset()`, arrays indexados, associativos e multidimensionais.
- **Sem uso de:** estruturas condicionais (`if`, `else`, `switch`, operador ternário) e estruturas de repetição (`foreach`, `for`, `while`).

## Como usar

- Resolva cada exercício diretamente nos arquivos `ex01.php` até `ex20.php`.
- Para executar um exercício no terminal:
  ```bash
  php aula02/ex01.php
  ```
- As sugestões de resolução estão na pasta `aula02/gabarito/`.
